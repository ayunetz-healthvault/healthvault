# Interactive design reference

Open `index.html` in a browser, or serve this directory with a local static HTTP server if required by your browser. All assets are included. On desktop, Compare views shows both experiences; on mobile select Main user or Parent. Try recording a dose, reviewing a sample document, adding a question and completing a task.

This is the display the founder approved in the conversation, copied from the private Koode prototype on 8 September 2026. The Nunito font was carried over from the user-supplied reference. No live patient reports, provider keys or cloud credentials are included.

This is a design artifact only: fixtures and browser-memory state simulate behavior. Do not ship this JavaScript as the native app, or reuse its simplified permission toggle as authorization logic. Do not add the demo comparison toolbar to production.

The prototype's Design notes dialog says the GitHub implementation has not been verified. That reflects the prototype's earlier creation date. The later source review is in `../BASELINE.md`, and the executable requirements are in `../STORIES.md`. The copied UI is preserved as the approved visual reference; its medical examples, processing assertions and simplified access behavior are not production guarantees.
